Free Airtable Web Clipper (Works on Airtable's Free Plan)

Want to save web pages into an Airtable table without upgrading your plan? ClipFlow uses an Airtable Personal Access Token, which works on the Free plan.

Why the official clipper may not fit

Airtable's own web clipper has been offered on paid plans, which rules it out if you are on Free. Plans change, so check Airtable's current pricing page before you decide. ClipFlow does not depend on that: it talks to Airtable's public API with a token you create yourself.

Set it up in a few minutes

  1. Create a token at airtable.com/create/tokens with the scopes data.records:write and schema.bases:read. Add the bases you want to save into.
  2. Paste it into ClipFlow Settings and press Test Connection.
  3. Add the Webpage → Airtable Record preset in Forms and choose your Base and Table.
  4. Map your fields. Match each Airtable column to a value. The preset maps Name to {{title}}, URL to {{url}} and Notes to {{selection}}. Rename or add columns to match your table.
  5. Clip. Open any page, optionally select text, open ClipFlow and press Save Clip. You can edit each field before it is saved.

Grab specific parts of a page with CSS selectors

Need a price, author or heading instead of the whole page? In the form, name a CSS selector (for example price = .product-price), then use {{css.price}} in any column to pull that element's text.

What is free

ClipFlow is free during the beta, with every feature unlocked. Your token stays in your browser and clips go straight from your browser to Airtable. No ClipFlow server sees them.

Frequently asked questions

Is there a free Airtable web clipper for the Free plan?

Yes. ClipFlow is a free Chrome extension that saves web pages to Airtable using a Personal Access Token, which works on Airtable's Free plan. Airtable's own clipper has been offered on paid plans, so check Airtable's current pricing.

What Airtable token scopes does ClipFlow need?

data.records:write and schema.bases:read, with access to the bases you want to save into. Create the token at airtable.com/create/tokens.

Can I clip only part of a page into Airtable?

Yes. Name a CSS selector in your form, for example price = .product-price, then use {{css.price}} in any column to save that element's text.

Does ClipFlow see or store my Airtable data?

No. There is no ClipFlow server. Your token stays in your browser and clips go straight from your browser to Airtable.
