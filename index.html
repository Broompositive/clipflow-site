Looking for a faster ClickUp Chrome extension?

If the official ClickUp extension slows your browser or logs you out, ClipFlow is built the other way round: no polling, no always-on scripts on other sites, and your token stays put until you remove it. It only runs when you press Save.

Set up in about a minute

  1. Paste your ClickUp API token and/or Airtable token in Settings.
  2. Press Test Connection.
  3. Add a preset form and choose your list or table.
  4. Clip with one click, or Ctrl+Enter.
